# PJ

PJ 是一款基于浏览器的项目工期排期与甘特图工具，适用于项目管理、施工安排、生产计划和任务协同场景。它提供了项目列表、任务维护、自动顺延排期、导入/导出数据、打印导出以及主题/品牌定制等能力，适合在本地快速生成和管理排期表。

## 功能概览

- 项目管理：新增、复制、切换项目
- 任务管理：新增任务、编辑名称、负责人、开始/结束时间、工期、进度
- 甘特图展示：直观显示任务排期、进度和时间轴
- 自动排期：支持按日期顺延和任务排序
- 导入导出：导出单项目或全部项目为 JSON，支持导入历史数据
- 排版输出：支持打印预览、导出表格样式与品牌设置
- 主题定制：浅色/深色模式切换，支持 LOGO 和文本品牌信息

## 运行方式

这个项目是纯前端静态页面，直接打开 index.html 即可使用。为了获得更稳定的本地访问体验，也可以用下面的方式启动一个简单的静态服务器：

```bash
cd /workspaces/PJ
python3 -m http.server 8000
```

然后在浏览器中访问：

```text
http://localhost:8000
```

## 使用说明

1. 打开应用后，可在左侧项目列表中创建或切换项目。
2. 通过“新增任务”按钮添加任务，并填写任务名称、负责人、开始日期、结束日期、工期和进度。
3. 使用“自动顺延排期”或“按开始日期排序”快速整理计划。
4. 可在“导入 / 导出”菜单中备份和恢复项目数据。
5. 使用“外观”菜单调整品牌、主题和显示设置。
6. 若需要打印或分享排期，可使用打印预览和导出方案。

## 说明

这是一个自用型排期工具，面向快速搭建和维护项目计划表的场景，适合本地管理，便于导出和复用。

## 维护建议

- 定期通过“导出全部”备份项目数据
- 对于需要长期维护的计划，建议在正式环境中再补充数据校验和权限控制
- 如需扩展功能，可在当前前端代码基础上继续增加筛选、权限、协同和云端保存能力
