PJ 是一款基于浏览器的项目工期排期与甘特图工具，适用于项目管理、施工安排、生产计划、任务跟踪和协同调度等场景。它以轻量、易用、可离线使用为核心目标，帮助团队快速梳理任务时间线、调整排期和输出可视化结果。

---

## About

PJ 的设计目标，是让项目管理者能够在不依赖复杂 SaaS 系统的前提下，快速生成高可读性的排期表。它适合：

- 个人或团队的任务推进管理
- 项目计划的阶段性安排
- 施工、生产、开发等周期性工作排期
- 需要本地保存、导出和打印的计划表

它不强依赖后端，所有核心能力均在前端完成，便于本地使用、快捷交付和二次开发。

---

## 核心功能

- 项目管理：新建、复制、切换项目
- 任务编辑：名称、负责人、开始日期、结束日期、工期、进度
- 甘特图展示：直观呈现任务时间轴和状态
- 自动排期：按日期顺延、按时间排序
- 数据管理：支持 JSON 导出/导入，便于备份恢复
- 打印与展示：支持排版输出、品牌定制、主题切换
- 本地化体验：无需后端即可直接在浏览器中运行

## 快速开始

### 方式一：直接打开

双击打开或使用浏览器直接访问项目中的 index.html，即可使用。

### 方式二：本地服务器

```bash
cd /workspaces/PJ
python3 -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000
```

---

## 使用流程

1. 在左侧项目列表中创建或切换项目
2. 点击新增任务，填写任务名称与负责人
3. 设定开始日期、结束日期或工期
4. 调整进度与显示设置
5. 使用自动顺延排期或按开始日期排序整理计划
6. 通过导入/导出功能备份与恢复数据
7. 需要时进行打印或分享

## 说明

这是一个偏“实用型本地排期工具”，更强调效率、简洁和快速落地，而不是复杂的企业级管理平台。适合在个人或团队工作流中直接使用，也适合作为后续扩展项目的基础模板。
